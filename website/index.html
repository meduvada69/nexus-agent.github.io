    One prompt in. A structured, cited comparison matrix out.

    You describe what you want to know. Nexus Agent does the clicking, checks its own work and hands back a table you can audit.

    1. Ask

      Give it a market or a list of competitors plus a goal, like “compare pricing at 50 seats”.

    2. Fan out

      The planner assigns each competitor to its own TinyFish agent, and they all run in parallel.

    3. Cite

      Every cell keeps its source link, a confidence score and the agent’s step trace.

    4. Track

      Scheduled re-runs diff the results and flag rival price moves.

    AI plans, acts and verifies. It isn’t a ChatGPT wrapper.

    Four stages, each with a job and a check. The language model never writes a number it didn’t get from a validated cell.

    Turn one goal into a task for every site

    A planner LLM converts your goal into plain-English TinyFish agent instructions, one task per competitor site.

    • One goal becomes as many tasks as there are competitors.
    • The LangGraph state machine moves each task through plan, dispatch, validate and retry.
    • Tasks fan out over a Redis queue, so competitors run concurrently.
    goal    Compare pricing at 50 seats
plan    3 tasks, dispatched in parallel

    Check every value before anyone sees it

    • Typed extraction. Pydantic schemas constrain every output.
    • Verifier loop. Confidence scoring plus cross-source checks. Low confidence triggers a refined retry.
    • Deterministic fallback. If an agent fails, the Fetch API’s markdown goes to a rule-based parser instead.
    cell         competitor-c / pro / 50 seats
schema       ✓ valid PriceCell
source_url   ✓ attached
cross-check  ✓ agrees with a second source
confidence   0.91 → accept

low confidence  refine goal → retry on Agent API
agent failure   Fetch API markdown → rule-based parser

    Write insights from validated data only

    The synthesis LLM only sees cells that passed validation, so there are no hallucinated prices. It writes grounded comparisons, gaps and positioning insights, each tied back to the cells it used.

    Agent API for what humans click. Fetch API for what pages say.

    TinyFish is the mandatory integration, and it’s also why this works at all. A router sends each page to the API that fits it.

    Why not Selenium or Playwright

    • Brittle selectors break on every redeploy.
    • We’d own proxies, stealth and CAPTCHA handling, and bot walls would still block us.
    • No goal-level reasoning: one script per competitor.
